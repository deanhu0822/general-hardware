# Balanced sector evaluation

The J12 paid service stays focused. A separate synthetic demo/evaluation library adds 64 connector-review cases: eight sectors × two products × documented, missing, conflicting and adversarial evidence. Each sector contributes eight cases; the default two-repeat plan has 128 runs per effort policy.

Read [the benchmark protocol](../../synthetic-assets/review-benchmark/README.md) from the repository root as `synthetic-assets/review-benchmark/README.md`. Open `/sample/coverage` to inspect and download inputs. Use `node scripts/evaluate-sectors.cjs` to validate/plan and `--smoke` for local test-double integration checks. Real Opus runs require explicit budgets and provider access.

Keep existing Rover/Terac study input hashes frozen. Do not feed expected answers to the runtime. Treat new keys as drafts needing independent review, and report model measurements separately from local structural tests. Equal fixture counts are experimental balance, not a claim of population fairness or exhaustive sector coverage.

Build: Fable 5.1 / High / 1M. Runtime: Opus 5.5 with the existing adaptive, bounded effort policy. shadcn/ui, Whop and actual Terac research remain the business requirements.
